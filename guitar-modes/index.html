What is a mode?

A mode is what you get when you play the notes of a major scale but start on a different note. Take C major: C D E F G A B. Start on D instead and play D E F G A B C D, and that is D Dorian. The notes are the same, but now D feels like home, so the whole scale sounds different. There are seven notes, so there are seven modes.

How to read the neck

Every dot is a note that belongs to the mode. The amber dot is the root, the home note the mode is named after. The pink dot is the one note that gives the mode its special sound. Purple dots are the rest. A dot to the left of the thick line at the start is an open string. The thin high e string is at the top, the same as in tab. Switch to NUMBERS to see each note's place in the scale: 1 is the root, and ♭3 means a lowered 3rd.

The seven modes, brightest to darkest

Lydian, Ionian (major), Mixolydian, Dorian, Aeolian (natural minor), Phrygian and Locrian. Each step along that list lowers one more note by a half step, which is why they get gradually darker.

Which mode should I play?

Start by matching the mode to the chord underneath you. Over a major chord, try Ionian, Lydian or Mixolydian. Over a minor chord, try Dorian, Aeolian or Phrygian. Over a minor 7♭5 chord, try Locrian. Then listen. The mode sounds right when its special note is not fighting a note in the chord.

Why do some notes have a flat or a sharp?

The notes are spelled to match the key, so you will see E♭ in a flat key rather than D♯. They are the same fret on the guitar. Only the name changes, so the scale uses each letter once.
