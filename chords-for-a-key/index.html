How the chords of a key are built

Every key is built from a seven-note scale. Stack thirds on each note of the scale, using only notes from that same scale, and you get seven chords: three major, three minor and one diminished in a major key. The Roman numerals tell you each chord's place in the key, with capitals for major chords and lower case for minor ones. In C major the chords are C, Dm, Em, F, G, Am and Bdim: I, ii, iii, IV, V, vi and vii°.

What the modes change

A mode starts the same seven notes from a different degree, which changes which chord is home. Dorian is the minor sound with a raised 6th, so the chord on the fourth degree is major rather than minor. Chords are spelled from the key's own letters, so you will see E♭ rather than D♯ in a flat key.
